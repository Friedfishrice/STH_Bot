An asynchronous, headless inventory monitor built with Python and Playwright to track hyper-local stock drops on Blinkit across multiple dark store catchment zones simultaneously. Features DOM isolation against recommendation carousels and instant Telegram webhook alerts.

Features
Concurrent Multi-Location Tracking: Uses asyncio.gather and isolated Playwright browser contexts with emulated geolocation coordinates to query multiple dark stores simultaneously without state collisions.

Robust DOM Heuristics: Filters false positives generated by "Similar Products" and "You might also like" carousels by scoping selectors to primary CTA containers and inspecting bounding-box layout coordinates.

Restock Phrase Detection: Accurately catches restock ETAs, "Notify Me" states, and "Back in stock" placeholders before triggering alerts.

Telegram Bot Webhook Alerts: Direct, low-latency push notifications via Telegram Bot API with configurable cooldown windows to prevent notification spamming.

Headless and Resource-Conscious: Reuses an active Chromium instance while rotating lightweight browser contexts.

Tech Stack
Python 3.10+

Playwright (Async API) for headless browsing and client-side DOM rendering

Requests for HTTP webhook dispatch

Telegram Bot API for real-time mobile push notifications

Getting Started
1. Prerequisites
Ensure you have Python 3 installed. Clone this repository and create a virtual environment:

git clone [https://github.com/your-username/blinkit-stock-tracker.git](https://github.com/your-username/blinkit-stock-tracker.git)

cd blinkit-stock-tracker

python3 -m venv venv

Activate the environment:

macOS / Linux: source venv/bin/activate

Windows (PowerShell): .\venv\Scripts\Activate.ps1

2. Install Dependencies
pip install playwright requests

playwright install chromium

3. Setup Telegram Bot Credentials
Message @BotFather on Telegram to create a bot and copy the TOKEN.

Start a conversation with your bot by pressing Start.

Message @userinfobot to retrieve your numeric CHAT_ID.

Set them as environment variables:

macOS / Linux:

export TELEGRAM_BOT_TOKEN="your_bot_token_here"

export TELEGRAM_CHAT_ID="your_chat_id_here"

Windows (PowerShell):

$env:TELEGRAM_BOT_TOKEN="your_bot_token_here"

$env:TELEGRAM_CHAT_ID="your_chat_id_here"

Configuration
Modify the configuration block in tracker.py:

PRODUCT_URL: Link to your target product on Blinkit.

CHECK_INTERVAL_SECONDS: How often to poll (e.g., 10 seconds).

ALERT_COOLDOWN_SECONDS: Cooldown between repeated Telegram alerts (e.g., 60 seconds).

LOCATIONS: A list of objects, each containing a name, latitude, and longitude.

Usage
Run the asynchronous monitor:

python tracker.py

Run Overnight on macOS (Prevent Sleep)
caffeinate -i python tracker.py

Run in Background on Linux
nohup python tracker.py > tracker.log 2>&1 &

Why Playwright Instead of Raw Requests?
Blinkit's quick-commerce storefront relies on dynamic client-side hydration and geo-derived session states. Scraping static HTML misses dynamically evaluated stock tags, while calling internal backend APIs directly requires maintaining session cookies and reverse-engineered headers. Playwright executes the page directly in headless Chromium with high reliability.
